# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions on topic. Harassment of any kind is not tolerated.

Report unacceptable behaviour privately via GitHub's **Report content** function or to the maintainer through the contact details on https://www.jacomeit.de.
